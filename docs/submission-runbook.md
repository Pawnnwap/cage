### 2. Deploy to Vultr and swap the demo URL

```bash
# on the Vultr VM (4 vCPU / 8 GB recommended)
git clone https://github.com/Pawnnwap/cage.git && cd cage
cp .env.example .env      # set VULTR_API_KEY, VULTR_MODEL, SANDBOXD_TOKEN
docker build -t cage-sandbox:latest sandbox_image
docker compose up -d --build
curl http://127.0.0.1:8080/healthz && curl http://127.0.0.1:8080/readyz
```

Then:

1. Open the public URL, run one real task through Vultr Serverless Inference.
2. Run all eight containment drills; keep the signed reports.
3. Export a task evidence pack and verify it:
   ```bash
   curl -s -H "Cookie: cage_owner=<value>" http://<vultr-ip>/api/tasks/<id>/evidence > evidence.json
   python scripts/verify_evidence.py evidence.json   # expect VALID
   ```
4. Pin the image digest and the evidence key fingerprint in the README, then
   replace the demo URL and the video in the submission.

## Things that will bite you

- The team tile is disabled before the event starts; that is expected, not a bug.
- The cover photo only persists after clicking **Save inside the cover modal** —
  the page-level Save does not commit it.
- The CookieYes consent modal can sit on top of the page and swallow clicks on
  "Edit cover" and "Change". Dismiss it first.
- The tech-tag field is an autocomplete, not free text: type, wait for the
  suggestion list, then click the `li` (the handler is `onMouseDown`, so a
  synthetic `click` alone does nothing).
- The profile picture upload is accepted but the header keeps the GitHub OAuth
  avatar; that is why the profile sits at 95%.
